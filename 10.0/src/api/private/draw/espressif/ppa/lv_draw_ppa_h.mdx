### lv_draw_ppa_rotate

Rotate a block with the PPA.

```c
lv_result_t lv_draw_ppa_rotate(const void *src, void *dst, int32_t src_width, int32_t src_height, int32_t src_stride, int32_t dst_stride, lv_rotation_t rotation, lv_color_format_t cf)
```

<span className="sr-only">Parameters</span>

| Name | Type | Description |
|------|------|-------------|
| `src` | `const void *` | pointer to the first source pixel |
| `dst` | `void *` | pointer to the first destination pixel |
| `src_width` | `int32_t` | source width in pixels |
| `src_height` | `int32_t` | source height in pixels |
| `src_stride` | `int32_t` | source stride in bytes |
| `dst_stride` | `int32_t` | destination stride in bytes |
| `rotation` | <ApiLink name="lv_rotation_t" /> | `LV_ROTATION_90`, `LV_ROTATION_180` or `LV_ROTATION_270` |
| `cf` | <ApiLink name="lv_color_format_t" /> | color format, only `LV_COLOR_FORMAT_RGB565` is accelerated |

**Returns:** <ApiLink name="lv_result_t" /> — `LV_RESULT_OK` if the PPA rotated the block, `LV_RESULT_INVALID` if the caller should rotate it on the CPU


</ApiMember>
