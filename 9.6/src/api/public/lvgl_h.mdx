### LV_VERSION_CHECK

```c
#define LV_VERSION_CHECK(x, y, z) \
    (x == LVGL_VERSION_MAJOR && (y < LVGL_VERSION_MINOR || (y == LVGL_VERSION_MINOR && z <= LVGL_VERSION_PATCH)))
```

Gives 1 if the x.y.z version is supported in the current version Usage:

- Require v6 #if <ApiLink name="LV_VERSION_CHECK" display="LV_VERSION_CHECK(6,0,0)" /> new_func_in_v6(); #endif
- Require at least v5.3 #if <ApiLink name="LV_VERSION_CHECK" display="LV_VERSION_CHECK(5,3,0)" /> new_feature_from_v5_3(); #endif
- Require v5.3.2 bugfixes #if <ApiLink name="LV_VERSION_CHECK" display="LV_VERSION_CHECK(5,3,2)" /> bugfix_in_v5_3_2(); #endif
