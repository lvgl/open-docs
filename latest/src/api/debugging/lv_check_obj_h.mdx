### LV_CHECK_OBJ_CLASS

```c
#define LV_CHECK_OBJ_CLASS(obj, cls, action) \
    LV_CHECK_ARG(obj != NULL, action); \
            LV_CHECK_ARG(lv_obj_has_class(obj, cls), action);
```

Check that `obj` is a descendant of the given class `cls`. Logs a warning and executes `action` if the check fails. Enabled when `LV_USE_CHECK_OBJ_CLASSTYPE = 1`; expands to a NULL check otherwise.

<span className="sr-only">Parameters</span>

| Name | Description |
|------|-------------|
| `obj` | Pointer to the object to check. |
| `cls` | Pointer to the expected `lv_obj_class_t` (e.g. `&lv_label_class`). |
| `action` | Statement to execute on failure (e.g. `return false`). |


</ApiMember>

### LV_CHECK_OBJ_VALID

```c
#define LV_CHECK_OBJ_VALID(obj, cls, action) \
    LV_CHECK_OBJ_CLASS(obj, cls, action); \
          LV_CHECK_ARG(lv_obj_is_valid(obj), action);
```

Check that `obj` is a live, reachable widget (i.e. part of the widget tree). Logs a warning and executes `action` if the check fails. Enabled when `LV_USE_CHECK_OBJ_VALIDITY = 1`; expands to nothing otherwise.

<span className="sr-only">Parameters</span>

| Name | Description |
|------|-------------|
| `obj` | Pointer to the object to validate. Must not be NULL. |
| `cls` |  |
| `action` | Statement to execute on failure (e.g. `return false`). |


</ApiMember>
