### lv_refr_clear_invalid_areas

Drop every invalidated area of a display, so nothing is redrawn because of them. It also drops the redraw requests the Widgets have made but the refresh has not turned into areas yet, so the display really is left with nothing to redraw.

```c
void lv_refr_clear_invalid_areas(lv_display_t *disp)
```

| Name | Type | Description |
|------|------|-------------|
| `disp` | <ApiLink name="lv_display_t" display="lv_display_t *" /> | pointer to a display |
