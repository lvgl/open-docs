### lv_opengles_pbuffer_get_gles_version

Get the OpenGL ES major version of the context backing a pbuffer display. ES3 is requested first, but drivers that cannot provide it fall back to ES2, where features needing ES3 shaders (e.g. glTF) are unavailable.

```c
uint8_t lv_opengles_pbuffer_get_gles_version(lv_display_t *display)
```

| Name | Type | Description |
|------|------|-------------|
| `display` | <ApiLink name="lv_display_t" display="lv_display_t *" /> | a display created by `lv_opengles_pbuffer_create` |

**Returns:** `uint8_t` — 3 or 2, or 0 if `display` is not a pbuffer display


</ApiMember>

### lv_opengles_pbuffer_create

Create a display that renders off-screen into an EGL pbuffer and reads the result back into its draw buffer, so no window system is needed.

The resolution and color format are fixed at creation; changing either on the returned display is not supported.

```c
lv_display_t * lv_opengles_pbuffer_create(int32_t hor_res, int32_t ver_res)
```

<span className="sr-only">Parameters</span>

| Name | Type | Description |
|------|------|-------------|
| `hor_res` | `int32_t` | horizontal resolution in pixels |
| `ver_res` | `int32_t` | vertical resolution in pixels |

**Returns:** <ApiLink name="lv_display_t" display="lv_display_t *" /> — the new display, or NULL on failure


</ApiMember>

### lv_opengles_pbuffer_destroy

Destroy a pbuffer context, releasing its GL objects and the EGL context.

This is deliberately not done when the display is deleted. Draw units may still run GL calls while they are being destroyed, and <ApiLink name="lv_deinit" display="lv_deinit()" /> deletes displays before draw units, so tearing the EGL context down from the display's delete event would pull the context out from under them. Fetch the handle with <ApiLink name="lv_opengles_pbuffer_get_handle" display="lv_opengles_pbuffer_get_handle()" /> beforehand and call this afterwards.

```c
void lv_opengles_pbuffer_destroy(lv_opengles_pbuffer_t *pbuffer)
```

<span className="sr-only">Parameters</span>

| Name | Type | Description |
|------|------|-------------|
| `pbuffer` | <ApiLink name="lv_opengles_pbuffer_t" display="lv_opengles_pbuffer_t *" /> | handle from `lv_opengles_pbuffer_get_handle`, NULL is ignored |
