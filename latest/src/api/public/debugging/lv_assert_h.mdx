### LV_ASSERT_INTERNAL

```c
#define LV_ASSERT_INTERNAL(expr, msg) \
    do { \
            if(!(expr)) { \
                LV_LOG_ERROR("Assertion `%s` failed." msg, #expr); \
                LV_ASSERT_HANDLER \
            } \
        } while(0)
```
