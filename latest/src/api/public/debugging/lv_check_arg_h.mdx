### LV_CHECK_ARG

```c
#define LV_CHECK_ARG(cond, action_on_fail) \
    LV_CHECK_ARG_INTERNAL_(cond, #cond, action_on_fail, "")
```

Check that a condition is true. If the condition is false, log a warning and execute `action_on_fail` (e.g. `return`, `return val`, `break`).

Can be disabled entirely by setting LV_USE_CHECK_ARG to 0 in lv_conf.h. If LV_CHECK_ARG_ASSERT_ON_FAIL is 1, LV_ASSERT_HANDLER is also invoked before the action. Log output requires LV_USE_LOG to be enabled; if LV_USE_LOG is 0 no output is produced regardless of LV_CHECK_ARG_LOG_MODE.

Example: 
```c
LV_CHECK_ARG(ptr != NULL, return);
```

<span className="sr-only">Parameters</span>

| Name | Description |
|------|-------------|
| `cond` | condition to check |
| `action_on_fail` | statement to execute on failure (e.g. `return`, `return 0`, `break`) |


</ApiMember>

### LV_CHECK_ARG_MSG

```c
#define LV_CHECK_ARG_MSG(cond, action_on_fail, msg) \
    LV_CHECK_ARG_INTERNAL_(cond, #cond, action_on_fail, " " msg)
```

Same as LV_CHECK_ARG but a message is appended to the log. The message is only used when LV_CHECK_ARG_LOG_MODE is set to VERBOSE.

Example: 
```c
LV_CHECK_ARG_MSG(ptr != NULL, return, "pointer must not be NULL");
```

| `msg` | string literal appended to the log message |


</ApiMember>

### LV_CHECK_ARG_FORMAT_MSG

```c
#define LV_CHECK_ARG_FORMAT_MSG(cond, action_on_fail, format, ...) \
    LV_CHECK_ARG_FORMAT_INTERNAL_(cond, #cond, action_on_fail, " " format, __VA_ARGS__)
```

Same as LV_CHECK_ARG but a printf-style message is appended to the log. The message is only used when LV_CHECK_ARG_LOG_MODE is set to VERBOSE.

Example: 
```c
LV_CHECK_ARG_FORMAT_MSG(len > 0, return -1, "len=%d", (int)len);
```

<span className="sr-only">Parameters</span>

| Name | Description |
|------|-------------|
| `cond` | condition to check |
| `action_on_fail` | statement to execute on failure (e.g. `return`, `return 0`, `break`) |
| `format` | format string literal appended to the log message |
| `...` | arguments of `format`; at least one is required |
