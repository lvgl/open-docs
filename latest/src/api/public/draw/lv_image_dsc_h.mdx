| Name | Value | Description |
|------|------|------|
| `LV_IMAGE_FLAGS_PREMULTIPLIED` | `0x0001` | For RGB map of the image data, mark if it's pre-multiplied with alpha. For indexed image, this bit indicated palette data is pre-multiplied with alpha. |
| `LV_IMAGE_FLAGS_COMPRESSED` | `0x0008` | The image data is compressed, so decoder needs to decode image firstly. If this flag is set, the whole image will be decompressed upon decode, and `get_area_cb` won't be necessary. |

### LV_IMAGE_HEADER_MAGIC

```c
#define LV_IMAGE_HEADER_MAGIC (0x19)
```

Magic number for lvgl image, 9 means lvgl version 9 It must be neither a valid ASCII character nor larger than 0x80. See `lv_image_src_get_type`.


</ApiMember>

### LV_IMAGE_HEADER_LEGACY

```c
#define LV_IMAGE_HEADER_LEGACY (0x00)
```

Magic number for legacy image resources that don't set magic field (v8 compatible). `lv_image_src_get_type` accepts this value as a valid image source.


</ApiMember>

<ApiMember kind="macro" name="LV_IMAGE_HEADER_DEADBEEF" file="public/draw/lv_image_dsc.h" line={37} url="https://github.com/lvgl/lvgl/tree/331ac10a6f2685f47ceab42d4ac843f99dfff97a/include/lvgl/draw/lv_image_dsc.h#L37">

### LV_IMAGE_HEADER_DEADBEEF

```c
#define LV_IMAGE_HEADER_DEADBEEF (0x1D)
```

Magic number set after lv_draw_buf is freed, used to detect use-after-free. If `lv_image_src_get_type` sees this value, the buffer has already been destroyed. Must be \< 0x20 and != LV_IMAGE_HEADER_MAGIC and != LV_IMAGE_HEADER_LEGACY.


</ApiMember>
