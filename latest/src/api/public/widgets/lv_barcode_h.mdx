### lv_barcode_set_data

Set the data of a barcode object and generate the bitmap. A copy of the data is stored, so a later property change can regenerate it. The properties may therefore be set before or after the data, in any order. An empty string clears the barcode.

```c
void lv_barcode_set_data(lv_obj_t *obj, const char *data)
```

<span className="sr-only">Parameters</span>

| Name | Type | Description |
|------|------|-------------|
| `obj` | <ApiLink name="lv_obj_t" display="lv_obj_t *" /> | pointer to barcode object |
| `data` | `const char *` | data to encode as a NUL terminated string |


</ApiMember>
