### lv_gstreamer_set_src

Add a source to this gstreamer object

```c
lv_result_t lv_gstreamer_set_src(lv_obj_t *obj, const char *factory_name, const char *property, const char *source)
```

<span className="sr-only">Parameters</span>

| Name | Type | Description |
|------|------|-------------|
| `obj` | <ApiLink name="lv_obj_t" display="lv_obj_t *" /> | pointer to a gstreamer object |
| `factory_name` | `const char *` | the factory name for the source of this gstreamer object. for common factory names, check `LV_GSTREAMER_FACTORY_XXX` defines |
| `property` | `const char *` | the property name for the gstreamer source object for common properties, see `LV_GSTREAMER_PROPERTY_XXX` defines **May** be `NULL`. When NULL the source object is created but its source is not set. |
| `source` | `const char *` | the property value for the gstreamer source object **May** be `NULL`. When NULL the source object is created but its source is not set. |

**Returns:** <ApiLink name="lv_result_t" /> — LV_RESULT_OK if the source was correctly set else LV_RESULT_INVALID


</ApiMember>
